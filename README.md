# WPS金山文档+其他云文档结合的Typora主题

## 介绍

- 非代码字体：Alibaba PuHuiTi 2.0，阿里巴巴普惠体
- 代码字体：Google Sans Code
- 字体行高：参考Trae
- 有序列表和无序列表颜色：参考飞书云文档
- 代码块设计：背景参考语雀和Notion、行高参考Trae
- 行内代码设计：参考Notion
- 目录侧边栏设计：参考Notion背景色
- 高亮块设计：参考Notion高亮块
- 图片样式设计：参考个人网站（www.help-doc.top）
- 引用块设计：参考飞书云文档和语雀
- 代码高亮：IntelliJ IDEA 新版默认高亮

## 使用

下载[主题CSS文件](https://github.com/H0308/Kdocs-new/blob/main/kdocs-new.css)放在Typora主题目录，重启Typora选择`Kdocs New`主题即可。如果需要字体文件，可以前往[字体目录](https://github.com/H0308/Kdocs-new/tree/main/fonts)进行获取，下载字体后在系统中安装字体，重启Typora即可
